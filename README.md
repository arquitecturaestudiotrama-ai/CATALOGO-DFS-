# DFS Studio · Catálogo de obras

Página web estática con el catálogo de obras de DFS Studio (30 obras).

## Contenido

- `index.html`: la página completa (estilos, tipografía y código incluidos).
- `img/`: las fotos de cada obra, en formato `.webp`. El nombre indica obra y orden: `p001-1.webp` es la foto 1 de la obra 001.

## Publicar con GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `dfs-catalogo`).
2. Subí `index.html`, la carpeta `img` y este `README.md` a la raíz del repositorio (botón **Add file → Upload files**, arrastrá todo junto).
3. En el repositorio, entrá a **Settings → Pages**.
4. En **Build and deployment**, elegí **Source: Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guardá.
5. Después de uno o dos minutos la página queda en `https://TU-USUARIO.github.io/dfs-catalogo/`.

## Probarla en tu computadora

Abrí `index.html` con doble clic en el navegador.
